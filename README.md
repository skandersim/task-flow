# TaskFlow 📋
Первое полноценное full-stack веб-приложение, которое я разрабатываю с августа 2026 года в одиночку для практики бэкенд и фронтенд разработки. Это не очередной пример из курса на 30 строчек кода — это полноценный личный таск-менеджер для планирования дел, над которым я постепенно работаю в свободное время.

## ✨ Что уже полностью реализовано
### 🔐 Аккаунты и безопасность
- Регистрация и авторизация по логину или почте
- Криптографическое хеширование паролей, пароли никогда не хранятся в базе в открытом виде
- Постоянные сессии для авторизации
- Полное удаление аккаунта со всеми личными данными

### ✅ Работа с задачами
- Создание задач с названием, описанием, дедлайном по дате и времени, приоритетом и категорией/хобби
- Редактирование и мягкое удаление задач
- Три статуса: не начато, в процессе, выполнено
- Отдельная история всех выполненных задач

### 👤 Профиль и прогресс
- Настраиваемый профиль с загрузкой аватара, именем, возрастом, хобби и личными целями
- Система уровней в зависимости от общего количества выполненных задач (от Новичка до Мастера)
- Постоянный счётчик продуктивности

### 📈 Дополнительные разделы
- Календарный вид всех предстоящих задач
- Страница подробной статистики продуктивности
- Раздел с настройками профиля
- Кастомный авторский дизайн интерфейса без сторонних UI фреймворков

## 🛠️ Стек технологий
- **Бэкенд**: Python, микрофреймворк Flask, модульная архитектура через блюпринты
- **База данных**: SQLite, написанные вручную параметризованные SQL-запросы без сторонних ORM
- **Фронтенд**: Чистый семантический HTML, кастомный CSS без готовых дизайн-систем, нативный JavaScript без jQuery и других дополнительных библиотек
- **Шаблонизация**: Jinja2

## 🚀 Как запустить локально
1.  Клонируй репозиторий на компьютер
2.  Создай и активируй виртуальное окружение
3.  Установи все необходимые зависимости:
    ```bash
    pip install -r requirements.txt
    ```
4.  Создай в корне проекта файл `.env` по примеру из `.env.example` и добавь в него случайный секретный ключ в переменную `FLASK_SECRET_KEY`
5.  Запусти приложение командой `python app.py`
6.  Открой в браузере адрес `http://localhost:5000`
